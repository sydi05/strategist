Convention: Zone 1 (capability names) — blue stickies, customer vocabulary preserved. Zone 2 (coverage) — green / yellow / red for full / partial / none. Zone 3 (maturity) — yellow sticky with 1–5 score and one-line rationale (required only if coverage is partial or full). Zone 4 (pain) — red / orange / pink for high / medium / low.

Horizontal grouping is load-bearing. Each capability's row of stickies must stay aligned. The plugin reads spatial alignment to link coverage, maturity, and pain to the capability.

Key pattern — horizontal row alignment. Unlike the Value Drivers workshop (which uses vertical parent-child grouping), the Current-State workshop uses horizontal row alignment. Each capability's coverage/maturity/pain stickies sit in the same row. The plugin reads horizontal position to link them. The facilitator must hold the room to this layout discipline — if stickies drift across rows, the extraction fails.
Sticky colour conventions
Blue — capability names (Zone 1)
Green — coverage: full
Yellow — coverage: partial / maturity score
Red — coverage: none
Dark red — pain: high
Orange — pain: medium / process pain (Zone 5)
Grey — systems (Zone 6) / parking
Purple — scope overflow (Zone 7)

Zone 1 · budget
"What budget envelope must this programme fit within?"
REQUIRED
AU$14M · TOTAL programme cap
AU$10M · Implementation
AU$4M · Year 1 run
Convention: green stickies. Format: "amount | currency | type (implementation / run / total)". Min 1.
Zone 2 · cost_tolerance
"Under what conditions would you flex the ceiling — and by how much?"
OPTIONAL
+AU$4M if FY27 deadline at genuine risk · CFO + Board re-approval
+AU$2M if Brand 4 carve-out demands a parallel checkout path · CEO sole approval
No flex on run cost — annual ceiling is firm
Convention: lime stickies. Format: "flex amount | condition | re-approval path". Empty zone is valid — it means the ceiling is hard. The strategist uses this to weight cost band widths in Output 5 option generation.

Zone 8 · red_lines
"What is absolutely off the table?"
CRITICAL · OPTION-GENERATION CONSTRAINT
RL-01 · No redundancies in commerce ops
RL-02 · No migration of NZ customer data outside NZ region
RL-03 · Brand 4 differentiated checkout must be preserved
Convention: dark red stickies. One red line per sticky. Every option generated in Output 5 MUST respect every red line in this zone — enforced at validation, not by convention. Zero red lines is valid; missing this zone is not.
Why this workshop runs after Gate A. Gate A approval often surfaces constraints the sponsor and steering body had not stated earlier — sometimes someone says "we approve the framing, but we need this done before financial year-end, which we hadn't said before." Running the Constraints workshop after Gate A captures the refreshed constraint set before options are generated against it. The workshop also feeds Output 9 (ROM); same workshop, two consumers.
Sticky colour conventions
Green — budget
Lime — cost tolerance / budget flex
Orange — deadlines
Red — regulatory
Blue — technology
Yellow — org readiness
Purple — assumptions
Dark red — red lines (hard constraints)
Grey — parking lot

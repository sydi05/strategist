# SiftFlow Strategist · Visual gallery

A single-page visual reference for the SiftFlow Strategist agent's outputs — every FigJam workshop and paint-back mockup rendered inline, every PowerPoint slide rendered as an image.

## What's here

5 outputs drafted (Vision, Value Map, Current-State, Stakeholder, Options) across the three template surfaces:

- **10 FigJam mockups** — 5 workshop frames + 5 paint-back surfaces
- **90 PowerPoint slides** — across 5 deck templates, rendered as JPEGs

Marlin Retail Group (fictional ANZ homewares retailer) is the example customer threaded through every mockup.

## Live site

Served via GitHub Pages — visit the Pages URL for this repo to view the gallery.

## Note on the FigJam mockups

These HTML files are visual specifications, **not** FigJam files. They show layout, zone structure, sticky conventions, and content patterns. Building the actual FigJam frame templates uses these as the visual reference — there's a translation step where the frame skeleton gets built in FigJam by hand.
